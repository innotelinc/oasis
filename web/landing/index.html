Email you host,
not email that hosts you.

Loomix pairs Stalwart's mail engine with the Loomix Mail client: email, calendars, contacts and files on your own infrastructure. Authentik identity, Cerulean DNS and certificates, NPM edge — one platform, with tenant administration, migration presets, health monitoring and compliance reporting.

Mail, calendars and collaboration — self-hosted.

A complete mail and collaboration platform — the engine, the client, the identity and the trust — self-hosted on your own infrastructure.

📧

Stalwart mail engine

SMTP, IMAP, JMAP and Sieve, with calendars, contacts and file storage in one Rust service and an embedded store.

🖥️

Loomix Mail client

Mail, calendar, contacts and files behind one login, with admin, settings, themes and plugins.

🔐

Authentik identity

One OIDC login for mail, admin and the rest of the estate; disable a user and their mail access dies.

🌐

Edge + wildcard TLS

app/api/auth/mail/files/admin hostnames provisioned in NPM with a wildcard Let's Encrypt certificate.

🛡️

Mail security

MX, SPF, DKIM, DMARC, MTA-STS and TLS-RPT posture with exit codes, `--json` output and dated Markdown reports.

📦

Migration presets

imapsync-based moves from Exchange, Google Workspace and Zimbra with per-provider presets.

🧑‍💼

Tenant administration

Domains, users and DNS zones from admin.<domain>, wired to Authentik and Stalwart in the same request.

🩺

Health monitoring

A daily host/TLS/SSO and mail-posture report, with the current result visible in the admin page.

The Mail layer of the stack.

One engine, one client, and the estate's identity and trust behind them.

📧

Stalwart core

Mailboxes, calendars, contacts and file storage in one embedded-store engine.

🖥️

Loomix Mail

The one client for mail, calendar, contacts, files and admin.

🔐

Authentik identity

OIDC SSO for the client and the admin surface, from the estate's identity provider.

🛡️

Cerulean trust

Authoritative DNS, DKIM publication and wildcard certificates, all through one bridge.
